# ECK MART Fashion Store

A responsive fashion storefront inspired by the supplied reference screenshot. Includes Men, Women, and Unisex clothing categories only.

## Included
- Responsive homepage and navigation
- Hero banner and product cards
- Category filters
- Add-to-bag counter and toast notifications
- Newsletter form demo
- Mobile navigation

## Run locally
Open `index.html` in a browser. Product photos are loaded from Unsplash, so internet access is needed for those images.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

This is a front-end demo. Checkout, payment, inventory, and account login are not connected.
